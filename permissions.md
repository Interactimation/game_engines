# Permissions Requests

For security reasons, Jan asks for permissions to do things like write to a folder
At your own risk, you may turn these off:

* Open Settings → MCP Servers
* Turn Allow All MCP Tool Permissions on

This automatically approves future MCP tool calls. Do not turn off the Filesystem server itself.

> **ALERT:** This setting is global: it pre-approves tools from every enabled MCP server, not only Filesystem. It is reasonably contained if Filesystem is the only enabled server and it is restricted to a dedicated folder\
