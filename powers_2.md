# Context Limits

Like most things in the computing world, there is a preference for [_powers of 2_](https://medium.com/@amoljadhav_48655/the-power-of-2-in-computer-science-fundamentals-79c69d1d950a)

Here are the most common context limits in Jan —stick with these exact values!

- `2048` — 2K
- `4096` — 4K
- `8192` — 8K
- `16384` — 16K
- `32768` — 32K
- `65536` — 64K
- `131072` — 128K
- `262144` — 256K

Do not set the context higher than the model supports or the computer can load!
